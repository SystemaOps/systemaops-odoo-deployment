# Odoo 18 Extra Addons

This directory contains custom Odoo 18 addons and OCA modules used in the SystemaOps deployment.

## Included Modules

- **Accounting & Finance**: `accounting_pdf_reports`, `om_account_accountant`, `om_account_asset`, `om_account_budget`, `om_fiscal_year`, etc.
- **Document Management (DMS)**: `dms`, `dms_field`, `dms_folder`, `enhanced_document_management`, `onlyoffice_odoo`, etc.
- **HR & Payroll**: `hr_dms_field`, `payroll`, `shift-planning`, etc.
- **Management Systems**: `mgmtsystem`, `mgmtsystem_audit`, `mgmtsystem_quality`, etc.
- **Social & Messaging**: `social`, `whatsapp_redirect`, `web_notify`, etc.
- **Theme & UI**: `muk_web_theme`, `muk_web_colors`, `muk_web_appsbar`, etc.

## Exclusion Rules

- No `.zip` archives should be pushed to this directory.
- No backup directories (`*_bkp`) should be pushed to this directory.
